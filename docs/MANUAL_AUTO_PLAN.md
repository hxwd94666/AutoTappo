# 自动/手动排列重构方案

> 状态：已实施（0.1.0）  
> 目标：把排列拆成全局“手动/自动”模式和房间级手动存档，简化槽位模型并修复手动偏移问题。

## 1. 总体规则

- 排列模式：手动 / 自动；
- 默认：手动；
- 手动在左，自动在右；
- 模式、自动配置为全局设置；
- 手动存档按房间保存；
- 删除独立“自动排列”开关；
- 开启高级开箱后，排列立即按当前模式生效；
- F6 手动布局仅在手动模式可用；
- 重叠属于自动模式，手动模式不可选。

## 2. 自动模式

- 房间最多 20 人：自己 + 19 个好友；
- 固定 19 个好友槽位；
- 不保存自动槽位；
- 自动槽位每次按配置计算；
- 自动配置全局共用：
  - direction：h-left / h-right / v-up / v-down / overlap；
  - wrap：0～20，包含自己；0 或空为到边缘；
  - wrapDir：横排上/下，竖排左/右；
- 多个方向共用同一份配置；
- 新好友填最低空槽；
- 好友离开时最小补位：最高占用槽移到空槽；
- 不生成第 20 个好友槽；
- F6 禁用；
- 不读取手动档；
- 主方向空间不足时反方向回退；
- 第一行/列与自己对齐；换行后新行/列从自己起点开始。

## 3. 手动模式

- 使用房间手动存档；
- 手动档为空：不做任何操作；
- 手动档存在：立即应用；
- 手动模式没有方向、换行数量、换行方向、重叠；
- F6 第一次进入编辑，第二次保存；
- 好友离开保留空槽，其他好友不自动补位；
- 新好友优先填最小空闲手动槽；
- 没有空闲手动槽：保持官方默认位置，不计算新位置；
- 用户 F6 拖动保存后，才创建新槽位；
- 空槽不绑定好友 ID。

## 4. 手动槽位编号

- 槽位编号按距离自己的距离升序；
- 自己越近，编号越小；
- 距离使用自己的可见区域中心到槽位中心；
- 距离相同：
  1. y 更小优先；
  2. x 更小优先；
- 槽位结构保存 x/y/w/h；
- 最多 19 个槽位，包括空槽。

## 5. 手动存档

按房间：

    autotappo-room-layout-v9:<account>:<room>
    {
      "version": 9,
      "manual": {
        "slots": [ { "x": 0, "y": 0, "w": 100, "h": 106 } ]
      }
    }

- 自动槽位不保存；
- 自动配置不保存到房间；
- 手动档为空表示完全没有手动布局；
- 旧 v8 数据不自动迁移，首次进入手动模式不做操作。

## 6. 手动重排

重排只改变槽位编号和 assignment，不改变槽位坐标。

触发时机：

- F6 保存时；
- 手动档载入时；
- 自己移动后下一次手动应用时。

规则：

1. 收集全部槽位（包含空槽）；
2. 收集当前好友占用的槽位；
3. 按距离排序；
4. 按新顺序重建 assignment；
5. 坐标不变；
6. 保存新顺序；
7. 不重新放置槽位，不造成位置跳动。

## 7. F6 保存

- 手动档为空：把当前所有在线好友位置写成初始槽位，按距离排序；
- 手动档已有：更新已分配槽位坐标；
- 未分配的新好友：在当前位置创建新槽位；
- 所有槽位重新按距离编号；
- 槽位坐标不主动改变；
- 不移动已有好友。

## 8. 模式切换

### 自动 → 手动

- 手动档存在：立即应用手动档；
- 手动档为空：什么都不做，保留自动模式刚算出的位置；
- 不恢复官方默认；
- 不创建手动槽位；
- 之后官方重渲染导致位置恢复默认，接受。

### 手动 → 自动

- 立即按全局自动配置重新计算；
- 手动档保留，不删除。

## 9. UI

布局区顶部：

    排列模式    [手动] [自动]

自动模式显示：

    排列方式    [横左] [横右] [竖上] [竖下] [重叠]
    换行数量
    换行方向
    手动布局    F6（禁用）

手动模式显示：

    手动布局    F6（可用）

- 删除“自动排列”开关；
- 手动模式显示自动方向/换行行，但全部禁用，不隐藏；
- 自动模式 F6 禁用；
- 重叠只属于自动；
- 手动模式下方向、换行数量、换行方向、重叠全部禁用但保持可见；
- 位置排列默认收起，不记忆展开。

## 11. 页面逻辑

- 自动：
  - 计算 19 槽；
  - assignment 填最低空；
  - 离开最大槽补最低空；
  - 不写手动档；
- 手动：
  - 读取房间手动档；
  - 档空：不修改任何 DOM；
  - 档存在：应用槽位；
  - 新好友填最低空槽；
  - 无空槽：不应用位置；
  - 离开保留空槽；
  - 不自动补位；
  - F6 保存/reindex。
